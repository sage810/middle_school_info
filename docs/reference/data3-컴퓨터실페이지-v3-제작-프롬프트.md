# "신현중학교 컴퓨터실 페이지 v3" 재현 프롬프트

아래는 다른 사람(또는 다른 AI)에게 그대로 전달하면, 지금 만든 컴퓨터실 페이지와 같은 수준의 기능을 갖춘 페이지를 새로 만들 수 있도록 정리한 프롬프트입니다. 그대로 복사해서 전달하시면 됩니다.

학교마다 다를 수밖에 없는 두 가지만 미리 알려드립니다.

- **NEIS Open API 키**: 지금 페이지에는 저희 학교 전용으로 발급받은 실제 인증키가 들어 있어서, 그 값 자체는 프롬프트에 넣지 않았습니다(다른 사람에게 그대로 넘기면 저희 학교 계정으로 API를 쓰게 되는 셈이라 위험합니다). 아래 프롬프트에는 "본인이 발급받은 키를 넣으라"는 자리표시자만 넣었습니다. 받는 사람은 https://open.neis.go.kr 에서 무료로 본인 학교 코드(시도교육청코드·표준학교코드)와 API 키를 직접 발급받아 채워 넣으면 됩니다.
- **수업 활동지(미션) 내용**: 지금 워크시트에 들어있는 실제 문제·정답은 저희 수업 진도에 맞춘 내용이라 "기능"이 아니라 "내용"입니다. 프롬프트에는 문제 내용 대신 "이런 형태의 활동을 넣을 수 있어야 한다"는 틀(활동 유형)만 담았고, 실제 문항은 받는 사람이 자기 수업에 맞게 채우도록 자리를 비워뒀습니다.

이 두 가지 외에는 화면 효과, 자동저장, 부정행위 방지, PDF 저장, 반응형, 접근성까지 지금 페이지의 기능이 최대한 빠짐없이 들어가도록 적었습니다.

## 여기서부터 복사해서 전달하세요

학교 컴퓨터실(정보실) 소개 겸 수업 활동지 페이지를 **HTML+CSS+JS가 전부 한 파일에 들어있는 단일 HTML 파일**로 만들어줘. 이 파일은 구글 사이트(Google Sites) 편집기의 "삽입 → 삽입할 코드" 기능에 그대로 복사해서 붙여넣을 용도야. 외부 파일을 따로 불러오지 말고(가능하면), 폰트와 PDF 저장용 라이브러리 정도만 CDN에서 불러와도 돼.

### 1. 전체 구조

- 상단에 **고정(sticky) 탭 바**를 두고, 이 안에 학교 이름/로고 텍스트와 탭 버튼들을 넣어줘. 탭은 4개: 🧼 이용 수칙, 🗓️ 시간표, 🍽️ 오늘의 급식, 📝 수업 활동지. 클릭하면 해당 섹션만 보이고 나머지는 숨겨지는 일반적인 탭 전환 방식으로 만들어줘 (`role="tablist"`/`role="tab"`/`aria-selected` 접근성 속성 포함).
- 페이지에 처음 들어오면 2~3초 정도 화면 전체를 덮는 **인트로 스플래시 효과**를 보여줘 — 가운데에 학교 이름 문구가 작게 시작해서 살짝 커지듯 나타났다가(팝인 애니메이션), 잠시 유지된 뒤 페이드아웃되면서 실제 페이지가 드러나는 순수 CSS 애니메이션으로. `prefers-reduced-motion`(동작 줄이기 설정)이 켜져 있으면 애니메이션 없이 훨씬 짧게 끝나도록 하고, 인쇄할 때는 아예 안 보이게 해줘.
- 전체적인 디자인은 Notion 스타일을 참고해줘: 흰색에 가까운 라벤더/오프화이트 배경, 채도 낮은 파스텬 포인트 컬러, 얇은 헤어라인 테두리, 그림자는 거의 안 쓰고, 버튼/카드는 살짝 둥근 사각형(진짜 알약 모양은 아님). 색상·폰트·여백·둥근 정도를 CSS 커스텀 프로퍼티(`:root` 변수)로 관리해서 나중에 바꾸기 쉽게 해줘. 폰트는 한글은 부드러운 느낌의 폰트(예: Gowun Dodum 등 구글 폰트), 영문/숫자는 별도 폰트를 조합해도 좋아.

### 2. 탭 1 — 이용 수칙

- 컴퓨터실 이용 규칙을 카드 4개(2×2 그리드, 모바일에서는 1열)로 보여줘. 각 카드는 이모지 아이콘 + 제목 + 설명 문장, 카드마다 서로 다른 파스텔 배경색.
- 마우스를 카드 위에서 움직이면 카드가 커서 쪽으로 아주 살짝 기울어지듯 따라오는 "wobble" 호버 효과를 넣어줘(터치 기기와 `prefers-reduced-motion`에서는 비활성화).
- 상단에 "오늘 날짜 카드"를 두고, 탭이 실제로 화면에 보이는 시점(스플래시가 끝난 뒤)부터 오늘 날짜와 요일을 타자기처럼 한 글자씩 타이핑되는 효과로 보여줘(예: "2026년 9월 2일 수요일"). 커서는 깜빡이는 막대로 표현하고, 이 탭에 다시 들어올 때마다 처음부터 다시 타이핑되게 해줘.

### 3. 탭 2 — 시간표 (NEIS Open API 연동)

- 학년 선택, 반 선택 드롭다운과 일간/주간/월간 보기 전환 버튼, 이전/다음 이동 버튼, "오늘로 이동" 버튼을 둬줘.
- 데이터는 **NEIS 나이스 교육정보 개방 포털(Open API)**의 중/고등학교 시간표 조회(`misTimetable`/`hisTimetable`) 엔드포인트를 `fetch`로 호출해서 가져와줘. 아래처럼 설정값을 코드 맨 위에서 한눈에 바꿀 수 있게 분리해줘:
  ```js
  var TT_CONFIG = {
    KEY: '여기에_본인이_발급받은_NEIS_오픈API_인증키_입력',
    ATPT_OFCDC_SC_CODE: '여기에_시도교육청코드_입력', // 예: 서울=B10, 경기=J10
    SD_SCHUL_CODE: '여기에_표준학교코드_입력'
  };
  ```
  (NEIS Open API 포털 https://open.neis.go.kr 에서 회원가입 후 무료로 발급받을 수 있고, 학교 코드는 그 사이트의 학교 검색 기능으로 찾을 수 있다는 안내 주석을 코드에 남겨줘.)
- 일간 보기에서는 교시별 시간(1교시 09:00~09:45 같은 식으로 실제 시간표에 맞게)까지 같이 보여주고, 오늘 날짜라면 지금 몇 교시가 진행 중인지 계산해서 "완료/진행중/예정" 상태를 표시해줘(30초마다 자동 갱신). 지금 정보 교과가 진행 중인 학급을 자동으로 찾아서 처음 진입 시 그 학년/반을 자동 선택해주면 더 좋아.
- 주간 보기는 월~금 5칸, 월간 보기는 달력 형태(7열) 그리드로 보여주고, 각 칸을 클릭하면 그 날짜의 일간 보기로 이동하게 해줘.
- 과목별로 고정된 색을 입혀서 시간표를 한눈에 구분하기 쉽게 해주고(목록에 없는 과목은 이름을 해시해서 몇 가지 색 중 하나로 일관되게 배정), 방학·휴업일처럼 하루 종일 같은 내용이 반복되는 날은 "교시별" 대신 그 문구 하나만 보여줘.
- 데이터가 없거나 API 호출이 실패했을 때 보여줄 안내 문구도 각각 만들어줘.

### 4. 탭 3 — 오늘의 급식 (NEIS Open API 연동)

- 구조는 시간표 탭과 거의 동일하게(일간/주간/월간, 이전/다음/오늘로 이동) 만들되, NEIS의 급식식단정보(`mealServiceDietInfo`) API를 사용해줘. 시간표와는 별도의 설정 객체(`NEIS_CONFIG`)로 API 키를 분리해줘(같은 포털에서 별도로 발급).
- 메뉴 이름에 붙은 알레르기 유발 식품 번호(괄호 안 숫자, 예: `(1.5.6)`)를 파싱해서 알레르기 이름 태그로 바꿔 보여주고, 그 외의 괄호(원산지 표기 등)는 화면에서 제거해줘.
- 메뉴를 밥/국/메인요리/나물/김치/후식/과일·음료 같은 카테고리로 자동 분류해서 서로 다른 색으로 표시해주면 가독성이 좋아져.
- 칼로리 정보도 함께 보여줘.

### 5. 탭 4 — 수업 활동지 (가장 중요한 부분)

이 탭은 교사가 수업마다 내용을 바꿔가며 재사용할 학습지야. 아래 "활동 유형"들을 모두 지원하는 재사용 가능한 컴포넌트로 만들어줘 (실제 문제 내용은 넣지 않아도 되고, 이런 유형의 활동을 넣을 수 있는 구조만 만들면 돼):

- **학생 정보 입력칸**: 학년(고정 텍스트)/반/번호/이름을 적는 짧은 입력칸.
- **진행률 표시줄**: 탭 바 바로 아래에 고정(sticky)으로 붙어서, "OO / 전체칸 완료 (XX%)" 형태로 보여줘. 답을 입력한 빈칸 개수 ÷ 전체 빈칸 개수로 계산하고, 입력할 때마다 실시간으로 갱신돼야 해.
- **순서도形 빈칸 채우기**: 여러 단계를 화살표로 연결한 순서도 모양 안에 빈칸을 넣어 채우게 하는 컴포넌트(가로 배치, 좁은 화면에서는 세로로 자동 전환).
- **표 안에 빈칸 채우기**: 일반 `<table>` 형태로, 각 칸에 답을 입력하는 짧은 입력칸이나 여러 줄 입력칸을 넣을 수 있게 해줘.
- **객관식 카드 고르기**: 카드 여러 개 중 하나(또는 여러 개)를 클릭해서 고르는 형태. 같은 그룹(`data-group` 같은 속성)으로 묶인 카드끼리는 하나만 고를 수 있게(라디오 버튼처럼) 해주고, 정답이 정해진 문제는 클릭 즉시 정답/오답을 색과 문구로 알려주는 유형과, 정답이 따로 없이 그냥 골라보는 유형 둘 다 지원해줘.
- **OX 퀴즈**: O/X 두 버튼 중 하나를 고르는 문항을 여러 개 늘어놓고, "정답 확인" 버튼을 누르면 한꺼번에 채점해서 각 문항에 초록(정답)/빨강(오답) 테두리와 표시를 해주고, "다시 풀기" 버튼으로 전부 초기화할 수 있게 해줘.
- **드래그 앤 드롭 짝짓기**: 이름표(칩)들을 위쪽 트레이에 늘어놓고, 아래 빈 칸들로 마우스 드래그해서 옮겨 놓는 짝짓기 활동. **터치 기기에서도 써야 하니, 드래그 대신 "이름표 클릭 → 놓을 칸 클릭"으로도 똑같이 놓을 수 있게** 만들어줘. "다시 섞기"(제자리로 되돌리기)와 "정답 확인"(칸마다 초록/빨강 표시 + "N개 정답 · N개 오답" 요약) 버튼도 넣어줘. 한 페이지에 이런 짝짓기 활동이 여러 개 있어도 서로 독립적으로 동작해야 해.
- **길이에 따라 자동으로 커지는 빈칸**: 여러 줄을 적을 수 있는 서술형 빈칸은 글자가 늘어나면 스크롤 없이 칸 높이가 자동으로 늘어나야 해. 문장 중간에 짧게 끼워 넣는 빈칸(예: "내가 좋아하는 것: ___")은 평소엔 작게 있다가, 답이 길어지면 먼저 가로로 넓어지다가 일정 너비를 넘으면 그때부터 줄바꿈되며 세로로도 늘어나는 형태로 만들어줘. (표 안에 있는 빈칸은 표의 다른 칸 너비까지 고려해서 너무 넓어지지 않게 적당히 제한해줘.)
- **안내 상자(콜아웃) 여러 종류**: "오늘의 목표"용(주황 계열), "힌트/팁"용(초록 계열), "AI 챗봇에게 물어보기"용(보라 계열, 질문 예시 + AI 답변을 요약해서 적는 칸 포함) 이렇게 최소 3종류를 만들어줘. 각각 왼쪽 색 띠 + 옅은 배경으로 구분되게.
- **미션(활동) 단위 구획**: 활동을 "MISSION 1, 2, 3…" 같은 단위 카드로 나누고, 미션마다 서로 다른 파스텔 색 헤더 바(제목 + 이모지 배지)를 자동으로 순서대로 입혀줘.
- 붙여넣기(Ctrl+V, 드래그로 텍스트 끌어넣기)를 막아서 학생이 직접 타이핑하도록 해줘 — 시도하면 "붙여넣기 대신 직접 입력해주세요" 같은 안내 문구를 잠깐 보여줘. 또한 매크로/자동입력 같은 비정상적으로 빠른 입력(예: 2초 안에 30자 이상, 분당 1000자 넘는 속도)도 감지해서 그 입력을 되돌리고 같은 안내를 보여줘(사람이 손으로 칠 수 있는 속도보다 훨씬 빠른 경우만 걸리도록 기준을 넉넉하게 잡아줘).

**자동저장**: 학생이 입력하는 내용을 `localStorage`에 실시간으로(입력 후 약 0.6초 뒤 저장, 너무 자주 저장하지 않도록) 저장해서, 페이지를 새로고침해도 이어서 작성할 수 있게 해줘. 짝짓기 칸에 놓은 이름표, 골라놓은 카드 선택도 함께 저장/복원해야 해.

**PDF로 저장하기 버튼**: 활동지를 채운 뒤 누르면 지금까지의 답을 담은 PDF 파일이 바로 다운로드되게 해줘(별도 인쇄 대화상자 없이). 조건:
- 이름을 안 적었거나, 전체 진행률이 너무 낮으면(예: 70% 이하) "다 채우고 눌러주세요" 같은 안내와 함께 저장을 막아줘.
- 화면 그대로 캡처하면 배경색/그라디언트 때문에 지저분해 보일 수 있으니, PDF용으로는 검은 글씨-흰 배경 버전으로 변환한 사본을 따로 만들어서 캡처해줘(여러 줄 입력칸은 일반 텍스트 상자로 바꿔서 줄바꿈이 잘리지 않게).
- 페이지가 넘어갈 때 표/카드/문항 중간이 잘리지 않도록, 안전한 위치에서만 페이지를 나누는 로직을 넣어줘.
- 파일 이름은 "학년+반+번호 이름 활동지.pdf" 형식으로 자동 생성해줘.
- 저장이 끝나면 자동저장해뒀던 내용은 지워줘(같은 컴퓨터를 다음 학생이 이어서 쓸 수도 있으니까).
- PDF 라이브러리(html2canvas + jsPDF 등)를 못 불러왔을 때는 브라우저 기본 인쇄 기능으로 대체되게 해줘.

### 6. 인쇄 스타일

- 인쇄(또는 PDF 대체 경로)에서는 인트로 효과, 상단 탭 바, "이용 수칙"/"오늘의 급식" 탭, 화면 전용 버튼류는 숨기고 "수업 활동지" 탭만 항상 보이게 강제해줘.
- 미션 헤더의 화려한 색은 인쇄에서는 흰 배경+검은 글씨로 바꿔서 잉크를 아끼게 해줘.

### 7. 접근성 & 반응형

- 탭 버튼에는 `role="tab"`/`aria-selected`, 모든 입력칸에는 의미를 알 수 있는 `aria-label`을 붙여줘.
- 버튼 터치 영역은 최소 44px 이상으로 해줘.
- 좁은 화면(모바일)에서는 여러 열로 된 표/그리드가 1~2열로 자연스럽게 줄어들게 해줘.
- `prefers-reduced-motion`이 켜진 사용자에게는 애니메이션 효과들을 최소화하거나 꺼줘.
