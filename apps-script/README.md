# apps-script — 활동지용 작은 API

활동지 페이지는 GitHub Pages 에 두고, **서버가 꼭 필요한 일만** 이 Apps Script 가 맡습니다.

| 기능 | 켜는 방법 | 하는 일 |
|---|---|---|
| 제출 | `site.config.json` 의 `"submit": true` | 학생이 "PDF로 저장하기"를 누르면 PDF 가 내 컴퓨터에 저장되는 것과 **동시에** 선생님 드라이브 `정보수업 제출/<차시>/` 폴더에 저장되고, `정보수업 제출 기록` 시트에 학년·반·번호·이름·빈칸 답이 한 줄씩 쌓여요. 교사용 페이지에서는 보내지 않아요. |
| NEIS 프록시 | `"neisProxy": true` | 시간표·급식 실시간 조회를 이 API 경유로 바꿔요. 인증키(NEIS_KEY)를 브라우저에 두지 않고 한 번에 전체 데이터를 받아요. |

`apiUrl` 이 비어 있으면 둘 다 꺼져 있고, 활동지는 예전과 똑같이 동작해요.

## 처음 배포하기 (10분)

1. <https://script.google.com> → **새 프로젝트** → 이름: `정보수업 API`
2. `Code.gs` 내용을 지우고 이 폴더의 **Code.gs 를 통째로 붙여넣기** → 저장
3. ⚙ **프로젝트 설정** → "appsscript.json 매니페스트 파일을 편집기에 표시" 체크 → 편집기에 생긴 `appsscript.json` 에 이 폴더의 내용을 붙여넣기
4. (선택) ⚙ 프로젝트 설정 → **스크립트 속성** 추가
   - `SUBMIT_TOKEN` : 아무 문자열(예: `shinhyun-2026`). 같은 값을 `site.config.json` 의 `submitToken` 에도 넣기
   - `NEIS_KEY` : NEIS 인증키 (NEIS 프록시를 쓸 때)
5. 위쪽 함수 목록에서 **setup** 선택 → ▶ 실행 → 권한 허용 (드라이브에 `정보수업 제출` 폴더와 기록 시트가 생겨요)
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (학생이 로그인하지 않아도 제출 가능)
   - 배포 → 나오는 **웹 앱 URL**(…/exec) 복사
7. 저장소의 `site.config.json` 수정 후 커밋·푸시 → GitHub Pages 가 자동으로 다시 배포돼요
   ```json
   { "apiUrl": "https://script.google.com/macros/s/…/exec", "submit": true, "neisProxy": false, "submitToken": "shinhyun-2026" }
   ```
8. 확인: 웹 앱 URL 뒤에 `?action=ping` 을 붙여 브라우저로 열면 `{"ok":true,…}` 가 보여야 해요.

## 코드를 고쳤을 때

**배포 → 배포 관리 → ✏ → 버전: 새 버전 → 배포.** 이렇게 하면 URL 이 그대로 유지돼요.
("새 배포"를 누르면 URL 이 바뀌어서 site.config.json 도 바꿔야 해요.)

## 알아둘 점

- **"모든 사용자"가 목록에 없으면** 교육청 계정의 관리자 정책으로 막힌 거예요. 개인 구글 계정으로 배포하거나,
  "도메인 내 모든 사용자"로 배포하고 학생이 학교 계정으로 로그인한 상태에서 쓰게 하세요.
- **동시 접속**: Apps Script 는 한 계정당 동시에 30건까지 실행돼요. 페이지는 GitHub Pages 가 보여 주고
  여기로는 짧은 제출 요청만 오기 때문에 보통 문제없고, 실패하면 브라우저가 자동으로 2번 더 다시 보내요.
  그래도 실패하면 학생 화면에 "PDF 는 저장됐으니 선생님께 알려 주세요"가 떠요.
- **토큰은 완벽한 잠금이 아니에요.** 페이지 소스에서 보일 수 있어요. 아무나 무작정 보내는 것을 줄이는 정도로 생각하세요.
- 제출 PDF 는 20MB 까지 받아요.
