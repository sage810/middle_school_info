# 디지털 데이터 — 기획

> /lesson-new 스킬이 채운다. 확정된 숫자·정답은 여기와 answers.json 에만 적고, 이후 바꾸지 않는다.

## 대상 · 시간
- 학년/반: 중학교 2학년 정보 (데이터 분석 단원 1차시)
- 차시 길이: 45분
- 틀(shell): 4탭(portal) — 06 복사. 이용 규칙 · 시간표 · 오늘의 급식 · 수업 활동지

## 원자료
- `input/데이터분석/데이터 1차시.pdf` (3쪽, 쪽마다 그림 한 장) — **학생이 작성한 판**이라 질문·활동 틀만 가져오고,
  학생 이름·학번·답은 쓰지 않는다. PDF 의 디자인·레이아웃은 무시하고 이 저장소 디자인(`docs/rules/design.md`)으로 만든다.

## 학습 목표
1. 아날로그와 디지털이 무엇인지 알 수 있어요.
2. 디지털 데이터가 무엇인지, 어떤 종류가 있는지 실생활 예와 함께 말할 수 있어요.
3. 디지털 데이터의 좋은 점과 조심해야 할 점을 설명할 수 있어요.

## 카드별 내용 (PDF 에서 옮김)

### 이 학습지는 이렇게 써요
이 학습지에는 인터넷 검색 활동뿐 아니라, AI 챗봇 '제미나이(Gemini)'에게 직접 물어보는 활동도 있어요.
**보라색 상자**가 나오면 Gemini 에 들어가서 질문을 입력하고, 돌아온 답을 내 말로 짧게 정리해 보세요.

### Tip
제미나이에게 물어볼 때는 '~을 쉬운 말로 설명해줘', '~을 예를 들어서 설명해줘'처럼 자세히 물어보면 더 쉬운 답을 받을 수 있어요.
답이 너무 어려우면 '더 쉽게 설명해줘' 라고 다시 물어보세요!

### MISSION 1 — 아날로그일까, 디지털일까?
- 안내: 아래 사진을 보고, 알맞은 이름표(아날로그·디지털)를 드래그해서 사진 옆 칸에 놓아보세요.
- 그림 4개(**새로 그림** — 사이트 디자인에 맞는 단순한 그림): 아날로그 시계 · 디지털 체온계(36.5 표시) · LP 레코드판 · 디지털 카메라
- 제미나이에게 물어보기 — 질문 예시: "아날로그와 디지털의 차이를 시계를 예로 들어서 쉽게 설명해줘." → 제미나이 답변 요약 [빈칸]

### MISSION 2 — 디지털 데이터, 넌 누구니?
- 📢 우리가 스마트폰과 컴퓨터에서 매일 쓰는 디지털 데이터에는 어떤 종류가 있을까? 하나씩 파헤쳐 보자!
- 제미나이에게 5가지 데이터 종류마다 실생활 예시를 각각 물어보고, 답을 정리해 보세요.
- 제미나이에게 물어보기 — 질문 예시: "문자 데이터의 실생활 예시를 하나 알려줘", "숫자 데이터의 실생활 예시를 하나 알려줘"
- 표: 데이터 종류 | 실생활 예시 — 문자 · 숫자 · 이미지 · 소리 · 동영상 데이터 [빈칸 5]
- ⭐ 미니 퀴즈: 친구들과 마라탕을 먹으러 가서 마라탕 사진을 찍고, 코르티스의 'redred' 음악을 배경음악으로 넣었다.
  이때 쓰인 디지털 데이터는 무엇일까? 해당하는 것을 모두 클릭하세요. — 보기: 문자 · 숫자 · 이미지 · 소리 · 동영상 데이터

### MISSION 3 — 디지털 세상의 빛과 그림자
- 📢 디지털 데이터는 정말 편리하지만, 무조건 좋기만 할까? 오늘은 디지털 세상의 편리함과 위험함을 함께 파헤쳐보자!
- ① [만약에... 상상해보기] 스마트폰과 인터넷이 하루 동안 완전히 사라진다면, 나의 하루는 어떻게 달라질까?
  검색하지 말고 먼저 스스로 상상해서 적어 보자. [빈칸]
- ② [비교해보기] 아래 상황을 인터넷·스마트폰 없이 처리한다면, 그리고 디지털로 처리한다면 각각 어떨지 예상해서 적어 보자.
  표: 상황 | 인터넷·스마트폰 없이 하면? | 인터넷·스마트폰이 있다면? — 친구 여러 명에게 연락하기 · 사진 100장 보관하기 · 궁금한 것 알아보기 [빈칸 6]
- 제미나이에게 물어보기 — 질문 예시: "아날로그 데이터와 비교해서 디지털 데이터의 장점에 대해 알려줘." → 답변 요약 [빈칸]
- 🕵 디지털이 꼭 좋은 것만은 아닐 수도 있다?! — 📢 디지털 데이터는 편리하지만, 조심하지 않으면 위험할 수도 있어요.
  (PDF 의 "실제로 어떤 일이 있었는지 뉴스로 확인해봅시다!" 문장은 **뺀다** — 선생님 결정 2026-09-30)
- 제미나이에게 물어보기 — 질문 예시: "아날로그 데이터와 비교해서 디지털 데이터의 주의할 점에 대해 알려줘." → 답변 요약 [빈칸]
