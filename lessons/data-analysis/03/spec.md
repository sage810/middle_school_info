## 카드별 내용 (PDF 에서 옮김)

### MISSION 1 — 데이터 과학은 어떤 순서로 문제를 해결할까?
- 📢 유튜버는 어떻게 인기 콘텐츠를 만들까? 그냥 느낌대로 찍는 게 아니라, 데이터를 분석해서 결정한다. 지금부터 나도 유튜버가 되기 위해, 데이터 분석이 무엇이고, 어떤 순서로 진행되는지 알아보자.
- ① 데이터 과학이 문제를 해결하는 과정 — 데이터 과학은 보통 다음 4단계 순서로 문제를 해결해요.
  1 문제 정하기 → 2 데이터 수집·특성 파악 → 3 데이터 분석하기 → 4 결과 해석·공유
  - 💡 각 단계 옆 문장의 빈칸에, 그 단계에서 하는 일을 알맞게 채워보세요.
  - 1: [ ] 분명히 정한다. / 2: [ ]에 필요한 데이터를 [ ]. / 3: 데이터의 [ ]과 [ ]를 찾아본다. / 4: 알아낸 것을 [ ]하고 다른 사람과 나눈다.
- ② 사례로 따라가기 — 내 유튜브 키우기: 위 4단계를 실제 "내 유튜브 키우기" 문제에 적용하면 이렇게 돼요.
  - 표(단계 | 내 유튜브 키우기 문제를 해결하기 위해서는): 1. 문제 정하기 / 2. 데이터 수집 및 특성 파악하기 / 3. 데이터 분석하기 / 4. 결과 해석하기

### MISSION 2 — 데이터 기반 의사 결정이란?
- 📢 유튜버의 콘텐츠뿐만 아니라, 세상의 많은 문제는 감이 아니라 데이터로 해결됩니다. 어떤 것이 진짜 데이터 과학 사례인지 살펴봅시다.
- 💡 데이터 기반 의사 결정이란? 데이터 기반 의사 결정: 단순히 [ ]에 의한 의사 결정이 아니라, 체계적으로 데이터를 [ ]하는 과정을 거쳐 전략적인 [ ]을 내리는 것
- 📖 사례 1 — △△엔터테인먼트 굿즈 판매량 늘리기 / 📖 사례 2 — OO 프로 스포츠팀 승률을 높이기 (❌ 직관에 의한 결정 · ✅ 데이터 기반 의사 결정 · → 결정 2줄씩, 문장은 lesson.html)
- 📋 판단의 열쇠: 결정을 내릴 때 실제로 데이터를 수집하고 분석했는지를 봅니다. 결과가 그럴듯해 보여도 [ ]과 [ ]에만 의존했다면 데이터 과학이라고 할 수 없어요.
- 🔑 이것도 데이터 과학 사례일까? 무엇을 보고 데이터 과학인지 아닌지를 가릴 수 있을까? 아래 두 사례를 보고 먼저 골라보세요.
