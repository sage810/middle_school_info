MISSION_2 CHECK
🎬
데이터 기반 의사 결정이란?

📢 유튜버의 콘텐츠뿐만 아니라, 세상의 많은 문제는 감이 아니라 데이터로 해결됩니다. 어떤 것이 진짜 데이터 과학 사례인지 살펴봅시다.

💡 데이터 기반 의사 결정이란?
데이터 기반 의사 결정: 단순히 에 의한 의사 결정이 아니라, 체계적으로 데이터를 하는 과정을 거쳐 전략적인 을 내리는 것
📖 사례 1 — △△엔터테인먼트 굿즈 판매량 늘리기
아이돌 엔터테인먼트 회사: "다음 시즌 굿즈 판매량을 늘리려면 어떻게 할까요?"
❌ 직관에 의한 결정 "글쎄요, 요즘 유행하는 캐릭터 인형이나 만들어볼까요? 아니면……"
✅ 데이터 기반 의사 결정 "지난 콘서트에서 판매된 굿즈 데이터를 분석합시다."
포토카드보다 슬로건(응원봉 장식)이 10대 팬층에서 훨씬 잘 팔렸으니, 다음 시즌엔 슬로건 종류를 늘립시다.
온라인 판매량이 콘서트 현장 판매량보다 3배 높으니, 온라인몰 재고를 더 확보합시다.
📖 사례 2 — OO 프로 스포츠팀 승률을 높이기
감독: "우리 팀 승률을 높이려면 어떻게 할까요?"
❌ 직관에 의한 결정 "글쎄요, 우선 유명한 선수를 영입해볼까요? 아니면……"
✅ 데이터 기반 의사 결정 "지난 시즌 경기 데이터를 분석합시다."
3쿼터 후반에 실점이 집중되는 걸 보니, 이 구간에 선수 체력 관리 훈련을 강화합시다.
특정 상대 팀과의 경기에서 특정 전술의 성공률이 낮으니, 다음 대결에서는 전술을 바꿉시다.
📋 판단의 열쇠
결정을 내릴 때 실제로 데이터를 수집하고 분석했는지를 봅니다. 결과가 그럴듯해 보여도 과 에만 의존했다면 데이터 과학이라고 할 수 없어요.

일상 속 데이터 과학 사례를 찾아보자

📢 데이터 과학은 이미 우리 일상 곳곳에서 쓰이고 있어요. 어떤 사례가 있는지, 그리고 그것이 우리 삶에 어떤 영향을 주는지 살펴봅시다.

① 데이터 과학이 쓰이고 있는 사례
사례데이터 과학개인의 삶이나 사회에 미치는 영향
내가 무엇을 언제까지 보고 들었는지의 기록을 분석하여, 취향이 비슷한 사람들이 좋아한 곡과 영상을 골라 보여 준다.
주문 시각, 가게와 집 사이의 거리, 조리 시간, 날씨, 배달원 위치 데이터를 분석하여 음식이 도착할 시각을 계산한다.
② 일상에서의 데이터 과학 사례 찾아보기

뉴스나 기사를 통해 일상에서 데이터와 데이터 과학이 활용된 사례를 찾아보고, 데이터 과학이 개인의 삶과 사회에 어떤 영향을 미치는지 적어봅시다.

💡 사례를 찾기 어렵다면? '~ 데이터 분석', '~ 빅데이터'로 기사를 검색해 보세요. 그리고 앞에 배운 판단의 열쇠를 적용해 봅시다. 실제로 데이터를 수집하고 분석했는지가 확인되어야 데이터 과학 사례입니다.

MISSION_4 WRITE
🔍
원래 있던 직업은 어떻게 달라지고 있을까?

📢 데이터 과학의 발전은 새로운 직업뿐 아니라, 이미 있던 직업이 일하는 방식도 크게 바꾸고 있다. 어떻게 달라지고 있을까?

① 달라지고 있는 직업

💡 '예전에는'과 '지금은'을 읽고, 어떤 직업의 이야기인지 직업 칸에 적어 보세요.

직업예전에는지금은
경험과 직감에 의존해 타이틀곡과 컴백 시기를 결정함음원 스트리밍 순간 반응, SNS 언급량, 해외 팬덤 데이터를 분석해 타이틀곡을 선정하고, 국가별 컴백 시기와 안무 포인트까지 데이터로 설계함
경험과 직감만으로 캐릭터 능력치를 조정함수백만 판의 실제 경기 데이터(승률·픽률·밴율)를 분석해, 어떤 캐릭터가 너무 강하거나 약한지 판단하고 패치 방향을 결정함
✏️ 두 사례에서 무엇이 공통으로 달라졌을까?
예전에는 일어난 일을 기록하고 관리했다면, 지금은 그 기록을 분석해서 앞일을 예측해요. 데이터 과학은 새로운 직업만 만들어 내는 것이 아니라, 이미 있던 직업이 하는 일 자체를 바꾸고 있어요.
⚠️ 주의 데이터 과학이 발전한다고 해서 기존 직업이 사라지는 것은 아닙니다. 다만 그 일을 하는 방식에 데이터를 읽고 활용하는 능력이 더해진 것입니다.
