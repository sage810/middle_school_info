## 카드별 내용 (PDF 에서 옮김)

### MISSION 1 — 유튜브 쇼츠 크리에이터의 파일 창고
- 📢 너는 이번 주말까지 쇼츠(Shorts) 영상을 완성해서 올려야 하는 크리에이터야! 노트북 폴더를 열어보니 촬영본, 대본, 음악, 썸네일까지 파일이 잔뜩 있어. 확장자의 정체를 알아야 제대로 편집할 수 있어!
- ① 나의 쇼츠 프로젝트 폴더를 정리해 보자! 아래 이름표를 각 파일에 어울리는 확장자 칸과 데이터 종류 칸으로 드래그해서 놓아보세요. 터치 기기라면 이름표를 한 번 클릭한 뒤, 놓고 싶은 칸을 클릭해도 됩니다.
  - 💡 각 줄의 첫 번째 칸에는 확장자를, 두 번째 칸에는 데이터 종류를 놓아주세요.
  - 💡 다 놓았으면 '✅ 정답 확인' 버튼을 눌러 채점해 보세요. '🔀 다시 섞기'를 누르면 처음부터 다시 풀 수 있어요.
  - 파일: 📄 대본_최종.txt · 🎥 촬영원본.mp4 · 🎵 배경음악_신남.mp3 · 🖼 썸네일_시안1.jpg · 🎬 편집완성본.mov
  - 이름표: .txt .mp4 .mp3 .jpg .mov · 문자와 숫자 데이터 · 동영상 데이터 · 소리 데이터 · 이미지 데이터
- ② 폴더 정리함 만들기: 아래 정리함 이름표를 각 확장자에 어울리는 칸으로 드래그해서 분류해 보자. (💡 버튼 안내 같음)
  - 확장자: .txt .pdf .jpg .png .gif .mp3 .wav .mp4 .avi .mov · 이름표: 📄 문서함 · 🖼 이미지함 · 🎵 음악함 · 🎬 영상함

### MISSION 2 — 내 생활 속 확장자 찾기
- 📢 인터넷과 스마트폰을 하게 되면 나도 모르게 여러 파일을 만들게 돼요. 어떤 확장자로 저장될지 예상해보자!
- 아래 상황에서 만들어지는 파일은 어떤 확장자를 가질지 예상해서 적고, 검색해서 확인해 보자.
- 표(상황 | 파일 확장자): 유튜브의 특정 장면을 스크린샷으로 캡처해서 저장했다 / 발로란트 게임을 하던 중, 내가 플레이하는 모습을 화면 녹화해서 저장했다 / 포켓로그 공략법을 메모장에 정리해서 저장했다
- 💡 Tip: 답을 잘 모르겠으면, 제미나이에게 물어보세요! 예) "유튜브의 특정 장면을 스크린샷으로 캡쳐해서 저장했는데, 이 때 파일 확장자가 어떤 걸로 저장돼?"

### MISSION 3 — .exe 파일이 뭘까?
- 📢 확장자 중에는 조금 특별한 친구가 있어요. 바로 .exe! 어떤 파일인지 알아보자.
- exe 파일이 무엇인지, 제미나이에게 직접 물어보고 답을 정리해 보자.
- 제미나이: "exe 파일이 무엇인지, 비유를 들어서 쉽게 설명해줘." / "게임 중에서 exe 파일 예시 알려줘" → 답변 요약 각각
- 💡 알고 있었나요? 발로란트 같은 PC 게임을 실행할 때도, 사실은 게임 폴더 안에 있는 'VALORANT-Win64-Shipping.exe' 같은 파일이 실행되는 거예요! exe 파일 안에는 컴퓨터가 실행할 수 있는 명령어(코드)가 들어있어서, 더블클릭하면 프로그램이나 게임이 켜져요.
- 🌶 미니 퀴즈: 발로란트가 실행될까? — 발로란트 실행 파일의 확장자를 'VALORANT-Win64-Shipping.exe'에서 'VALORANT-Win64-Shipping.gif'로 바꿔버렸다! 이 상태로 더블클릭하면 발로란트 게임이 실행될까? (먼저 생각해보고, 검색해보세요!)
  - 🙋 나의 선택은? ① 실행된다 — 왜냐하면 발로란트를 구성하고 있는 다른 파일들은 그대로 있으니까 ② 실행되지 않는다 — 왜냐하면 확장자가 바뀌었으니까

### MISSION 4 — 유튜버가 되려면?
- 📢 유튜버가 되려면 영상 편집이 필요하다. 준비물은 무엇이 있을까?
- 제미나이 4개(→ 답변 요약 각각):
  1. "나는 [게임 / 댄스 / 일상 브이로그 / 공부]를 주제로 채널을 운영하는 유튜버로 데뷔하려고 해. 너는 이제부터 날 도와주는 매니저야. 구독자들의 눈길을 사로잡을 만한 신선하고 재미있는 채널 이름 3개랑 첫 영상 아이디어를 추천해 줘."
  2. "영상을 만들어서 유튜브에 올리려면 어떤 파일들이 필요해? 유튜브 영상 제작에 쓰이는 동영상, 이미지, 음성, 자막의 주요 파일 확장자 종류와 특징을 한눈에 볼 수 있게 표로 정리해 줘."
  3. "요즘 유튜버들이 영상 편집할 때 쓰는 프로그램은 뭐야?"
  4. "동영상 화질은 좋지만 용량이 큰 확장자와, 동영상 용량은 적당하면서 유튜브에 올리기 제일 좋은 확장자는 각각 뭐야?"
