# 「활동지 양식.docx」로 새 차시 만들기 (2026-09-30)

선생님이 `docs/templates/활동지 양식.docx` 에 내용을 적어 와서 **"이 양식으로 N차시 만들어줘"** 라고 할 때 따른다.
PDF 로 만들 때(`from-pdf.md`)와 흐름·부품·확인은 같고, **읽는 법과 표기 해석**만 다르다.

## 1. 읽기

이 PC 는 Read 도구·pandoc 으로 docx 를 못 연다 → 설치 없이 도는 읽기 도구:

```
node .claude/skills/lesson-new/references/docx-read.mjs "<채운 양식.docx>" > <scratchpad>/양식.md
```
- 제목 1~3 → `#`, 목록 → `-`/`1.`, 표 → `| 칸 |`(칸 안 여러 줄은 `<br>`), 문서 안 그림 → `[문서 안 그림]`.
- Word · Google 문서(파일 → 다운로드 → .docx) 둘 다 된다. 문서 안 그림이 있으면 파일로 따로 달라고 한다.
- **`# ✍️ 여기부터 작성` 아래만** 내용이다. 그 위(1. 이렇게 써요 · 2. 활동 표기법 · 3. 작성 예시)는 설명이라 무시.
- `※` 로 시작하는 줄은 양식의 안내 문구 — 무시.
- 양식에 학생 이름 같은 개인정보가 있으면 쓰지 않는다.

## 2. 표기 → 부품 (`from-pdf.md` §2 표의 부품을 쓴다)

| 양식 표기 | 부품 |
|---|---|
| `[[정답]]` (문장 속) | 문장 속 글자 칸 `.st-mean` + `textarea.blank.blank--inline`(03). 정답은 `answers.json` fill |
| `[[ ]]` | 같은 칸, 정답 없음(정답지 비움) |
| `[쓰기 칸 N줄]` · `예시:` | `textarea.blank rows=N`. 예시 답은 기본 정답지에서 비움(기본 정보 표의 "정답지에 채울 칸"이 "예시 답도"면 채움) |
| `[안내]` · `[Tip]` · `[주의]` | `.callout--info` · `.callout--reason` · `.callout--info`(⚠️ 라벨) — 콜아웃은 냉색만 |
| `[제미나이]` | `.callout--gemini` + 질문 예시 + 정리 칸 |
| 워드 표(`[표]`) | `.type-scroll > table.type-table`, 칸 안 `[[…]]` 은 `textarea.blank` |
| `[하나 고르기]` | 문항 1개 `VQ`(02) · 여러 개 `DQ`/`FQ`(03·06). `(정답)` 보기, `이유:` 는 오답 피드백(없으면 새로 씀) |
| `[모두 고르기]` | `MQ` + 정답 확인(01) |
| `[O/X]` (`→ O` / `-> X`) | `OXQ` + 정답 확인 · 다시 풀기(02·03). `(이유: …)` 는 틀렸을 때 문구 |
| `[이름표 끌어 놓기]` (`칸 → 정답`) | 공용 `chip-slot`, 여러 개면 `data-ca-group` + 버튼 채점(02) |
| `[순서 배열]` | `seq-order`(04) |
| `[그림]` | 새 SVG(`from-pdf.md` §6) 또는 받은 파일 |
| `[붙여넣기 칸]` | `paste-zone`(06) |
| `[링크]` | 새 탭 버튼(`.gm-btn` 모양) |
| `[메모]` | 만드는 방법 부탁 — 활동지에 넣지 않는다 |

- 기본 정보 표 칸이 비었으면 표에 적힌 기본값(4탭 · 바로 공개 · 맨 앞 안내 넣기 · 정답 있는 칸만)을 쓰고 **알린다**.
- `(물어봐 줘)` 가 적힌 곳, 표기가 모호한 곳은 AskUserQuestion 으로 묻는다(한 번에 4개까지).
- 표기법 없이 말로 적은 활동은 뜻대로 가장 가까운 부품을 고르고, 고른 것을 spec.md 와 보고에 적는다.

## 3. 그다음

`from-pdf.md` §4(폴더 · spec.md) → §5(조립) → §7(확인)과 똑같이. spec.md 의 원자료에는 양식 파일 이름을 적는다.
채운 양식 파일은 `input/<단원>/` 에 두고 커밋하지 않는다.

## 양식 고치기

양식 원본은 `references/template-docx.mjs`(docx 패키지는 scratchpad 에만 설치) → `docs/templates/활동지 양식.docx`.
표기를 새로 만들면 이 파일 §2 표와 양식의 「2. 활동 표기법」 표를 같이 고친다.
확인: `docx-read.mjs` 로 다시 읽어 구조가 그대로인지, Word(COM)로 HTML 저장해 캡처해서 눈으로.
